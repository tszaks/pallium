# v0.10.1 — Cursor, first-class

Pallium now treats Cursor like Codex, Claude Code, and Devin: workflows can run
Cursor-backed workers, teams can give Cursor teammates a persistent chat, and
session awareness sees Cursor chats from both the IDE and the `cursor-agent`
CLI. Run `pallium` from inside a `cursor-agent` session and it adopts Cursor
automatically.

## What's new

- **Cursor as a workflow provider.** `agent(..., { provider: "cursor" })` runs
  `cursor-agent -p --output-format stream-json` with the prompt on stdin and
  reads the answer, chat id, and token counts from the stream. Read-only agents
  run `--mode ask`, which removes the edit and shell tools; edit/test/check
  agents run `--force`. Steering detection recognizes Cursor via
  `CURSOR_AGENT` and checks it before `CLAUDECODE`, because `cursor-agent`
  child shells inherit the outer environment.
  `PALLIUM_WORKFLOW_PROVIDER_CURSOR_COMMAND` still overrides with a wrapper.
- **Cursor teammates with chat continuity.** Team members on Cursor resume the
  same chat across turns with `--resume`.
- **Cursor in `pallium sessions`.** `sessions live`, `watch`, and `find` list
  Cursor chats (IDE and CLI) with project, first ask, last action, and running
  terminal commands. New `--provider` filter on `live`, `watch`, and `find`.
- **Cursor session memory.** `sessions index`/`sync --provider cursor`
  (`--cursor-root` for a non-default folder) index Cursor transcripts, so
  `search`, `recall`, `show`, and `read` answer from them with `cursor:`
  citations.

## Known limitations

- **Cursor edit agents may reach the network regardless of `network: true`.**
  `--force` allows network tools. A networked read-only request is not granted.
- **Cursor cost is not tracked in USD.** The stream reports token counts only,
  so cursor joins codex and devin on the untracked-cost list.
- **Cursor recency is approximate.** Cursor writes no per-line timestamps, so
  live status uses the transcript file's modification time, and a running
  terminal is credited to the workspace's most recently active chat (terminal
  files are per workspace, not per chat).
- **Cursor's formats are undocumented.** Parsers skip unknown lines and never
  crash, but a Cursor update can change what Pallium can see.

## Install

```bash
npm install -g pallium
pallium version
```
